FONCTION DE HACHAGE
=========================================================

AUTEUR(S) : Simon Drolet, Marc-Antoine Leblond
DATE DE CRÉATION : 29 avril 2025

DESCRIPTION :
-------------
Fonction de hachage custom et calcul d'uniformité à l'aide de la formule Chi-carré.

COMMANDE D'ÉXÉCUTION :
-----------------------------------
type [fichier en entrée] | python HashFunction.py [taille de l'histogramme] > .\histo.txt
(Exemple): type .\mots.txt | python HashFunction.py 100 > .\histo.txt
